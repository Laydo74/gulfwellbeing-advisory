# GULFWELLBEING website and CMS

## Scope
- Build all 9 required public URLs with the exact 7-item main navigation and all 22 anchored sections.
- Create a premium ivory, charcoal, forest and restrained-gold editorial design based on the supplied reference.
- Add an owner-only admin area for editing, publishing, reordering and deleting site content, articles, categories, contact details and imagery.
- Use Lovable Cloud for secure owner authentication, structured content, and image storage. No separate user profile data will be stored.

## Public experience
- Shared responsive header, full-screen mobile navigation, footer, calls to action and subtle reduced-motion-safe reveals.
- Dedicated Home, Wellbeing, Women, Men, Business & Executive, VIP Concierge, About, Booking and Blog pages.
- Booking request form with validation, country/session/contact preferences and clear success/error states.
- Published CMS content displayed publicly with curated fallback content so the site remains complete from first launch.
- Unique metadata and semantic structure for every public page.

## Content management
- Structured records for page copy, repeatable sections, global settings, blog categories, posts and booking enquiries.
- Secure owner role stored separately from authentication, with owner-only policies and server-side checks.
- Admin screens for overview, page content, journal, global settings, enquiries and image uploads.
- Draft/published states and display ordering where relevant.

## Technical details
- TanStack Start routes and reusable React components.
- Lovable Cloud tables with row-level access rules and explicit grants.
- Public read functions return only published content; protected write functions validate authentication and owner role.
- Fast responsive images, lazy loading, keyboard navigation, focus states, labels and RTL-ready logical layouts.
- Seeded editorial content contains no invented credentials, testimonials, contact details or results.

## Verification
- Confirm all 9 URLs and 22 anchors.
- Check navigation, mobile menu, forms and calls to action.
- Verify public content loading, owner protection and admin editing paths.
- Check desktop and mobile layouts, accessibility basics, runtime errors and final build status.
